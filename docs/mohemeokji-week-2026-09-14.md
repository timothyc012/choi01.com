## 수정한 오류

가공상품이 생재료 가격에 섞이던 케첩·건조 토마토·피클·버터케제·과일/대체 요거트·쌀 디저트·또띠아 칩·통조림 참치 등을 제외한다. 일반 양파와 대파도 구분한다. 실제 바나나 상품명은 보존하면서 원산지 접두어를 인식한다.

할인 매칭이 0건인 조합도 안정적인 지점 ID를 갖는다. 달걀의 종 정보가 닭이라는 이유로 닭고기 조리 증거를 요구하던 오류와 `구워`/시간이 명시된 전자레인지 조리 문구 누락을 고쳤다. 회·토치·미조리 동물성 재료 차단 회귀 테스트는 유지했다.

브라우저는 Europe/Berlin 날짜에 유효한 상품만 가격과 추천에 사용한다. 9/14 화면에 9/17 시작 상품이 보이던 오류를 고쳤다. 원본 레시피 참조는 남겨 저장한 식단을 복원한다. 첫 추천에 독어 상품명·단위·가격·기간과 전체 구매비 미확인 상태를 표시한다. 단계 출처 주석의 숫자가 장보기 재료명을 자르던 오류도 수정했다.

## 남은 범위

영양·다이어트는 계량 영양 근거, 가성비는 완전한 장바구니/인분/포장 근거가 없어 비활성 상태를 유지한다. 채식 버튼은 메뉴 목록 필터이며, 기존 수동 식단을 자동으로 바꾸지 않는다. 비건·알레르기 보증이 아니다. 수량이 없는 재료, 가변 중량, 정규화되지 않은 단위는 확인이 필요하다.

파프리카 달걀찜과 파프리카 달걀볶음은 반찬으로 바로잡았다. MCP의 탐색 메뉴는 확인된 할인 재료와 정상가격 미확인 추가 재료를 구분하며, 한 번에 20개와 다음 `offset`을 반환한다. 탐색 메뉴의 후기·총비용·영양은 근거가 없으면 표시하지 않는다.

독립 코드 검토와 추가 변경 검토에서 구체적 정확성·보안 회귀가 발견되지 않았다. 표본 가격으로 되돌리는 경로를 추가하지 않았다.

02Ontology에는 주간 게시 action과 `meal_release_preview` → `meal_release_submit` →
`meal_release_approve` → `meal_release_resume` 흐름이 등록되어 있다. 일반 주간
데이터 갱신은 새 manifest의 `discoveryCatalogPath`를 통해 MCP가 같은 공개
snapshot을 읽으므로 패키지 재배포 없이도 반영된다. [연결 설계](mohemeokji-mcp-integration.md)에
도구 권한과 검증 순서를 정리했다.
