요청하는 Google 권한

  • https://www.googleapis.com/auth/gmail.readonly — 소유자 본인의 메일을 읽어 개인 업무 정리(할 일·일정 확인)에 씁니다.
  • https://www.googleapis.com/auth/gmail.send — 소유자가 직접 확인한 메일만 소유자 본인의 계정에서 보냅니다.

데이터를 저장하고 처리하는 곳

Google에서 받은 데이터는 소유자 본인 기기(개인 PC의 로컬 데이터베이스)에만 저장하고 처리합니다. 제3자에게 제공하거나 판매하지 않으며, 광고에 사용하지 않습니다.

사람이 데이터를 열람하는 경우

데이터를 열람하는 사람은 소유자 본인뿐입니다.

권한 철회와 데이터 삭제

  • 접근 권한은 언제든 https://myaccount.google.com/permissions 에서 “02ontology Personal”을 선택해 철회할 수 있습니다.
  • 로컬에 저장된 데이터의 삭제는 timothyc012@gmail.com으로 요청하면 처리합니다.

Google API 서비스 사용자 데이터 정책 준수

02ontology Personal이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함해 이를 준수합니다.

Effective date: 15 October 2026

What this app is

“02ontology Personal” is a personal tool used only by its owner (timothyc012@gmail.com). It is not a public service and does not accept connections from anyone else’s Google account.

Data received from Google is stored and processed only on the owner’s own device (a local database on a personal computer). It is not shared with or sold to third parties and is not used for advertising.

Human access

The only person who views the data is the owner.

  • Access can be revoked at any time at https://myaccount.google.com/permissions by selecting “02ontology Personal”.

Google API Services User Data Policy

02ontology Personal’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and changes

Contact: timothyc012@gmail.com. If this policy changes, this page is updated and the effective date revised.
